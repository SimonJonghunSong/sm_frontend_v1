  
# ST Sync MASTER

## 개요

ST SUNLAB에서 제작한 차량 추적기의 종합적인 관리와 설정을 돕기 위한 웹 서비스입니다. 본 플랫폼은 실시간 위치 추적, 차량 내부 설정 조정, 모델 프로파일 관리 및 다운로드 등 차량 관리의 전반적인 기능을 제공하여, 사용자의 효율적인 차량 관리를 지원합니다.

## 기술 스택

사용된 주요 기술 스택을 나열하세요.

- **프론트엔드**: React, Next.js
- 기타 라이브러리: Zustand, TanStack Query, Mui

## 설치 및 실행

로컬 환경에서 프로젝트를 실행하는 방법을 설명합니다.

1. 저장소를 클론합니다.

   ```bash
   git clone https://github.com/username/repository.git
   ```

2. 프로젝트 디렉토리로 이동합니다.

   ```bash
   cd repository
   ```

3. 의존성을 설치합니다.

   ```bash
   npm install
   ```

4. 로컬로 실행합니다.

   ```bash
   npm run dev
   ```

5. 프로덕션 모드로 실행하기 위해서는 build 후 start 합니다.
   ```bash
   npm run build
   npm run start
   ```

## 주요 기능

- 차량 설정 관리: 차량 추적기의 내부 설정을 변경하고 조정할 수 있습니다.
- 모델 프로파일 관리 및 다운로드: 특정 모델에 대한 프로파일을 관리하고 다운로드할 수 있는 기능을 제공합니다.
